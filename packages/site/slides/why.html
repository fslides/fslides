Why

Your slides deserve the same workflow as your code.

slides/*.html
Every slide is a plain HTML file. Any CSS, any JS, any library, any animation — if a browser renders it, it's a slide. No proprietary format, ever.
git push
The deck is a repo. Branches, PRs, reviews, history — collaboration you already know. CI builds and publishes to GitHub Pages on merge.
agent-native
HTML in, HTML out: AI agents author fslides decks fluently — no plugin, no export dance. Point Claude at a deck repo and say "make me a slide".
